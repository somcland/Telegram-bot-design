# Design News Bot

Telegram-бот, который каждый день в 10:00 по Москве собирает новости о российском дизайне
и присылает новые в чат или канал. Работает бесплатно на GitHub Actions,
сервер не нужен.

**Источники:** Sostav, Cossa (фильтр по дизайн-словам), Хабр · хаб «Дизайн» (всё подряд).

---

## Запуск за 10 минут

### 1. Создай бота
1. В Telegram открой **@BotFather** → `/newbot` → придумай имя.
2. Скопируй токен вида `123456:ABC-...`.

### 2. Узнай, куда слать
- **В личку:** напиши своему боту любое сообщение, затем открой
  `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найди `"chat":{"id": 12345678}`.
- **В канал:** добавь бота в канал администратором. Chat ID — это `@имя_канала`
  (для приватного канала — число вида `-100...` из того же `getUpdates`).

### 3. Залей код на GitHub
1. Создай новый репозиторий (можно приватный).
2. Загрузи туда все файлы из этой папки, **включая** `.github/workflows/design-news.yml`.

### 4. Добавь секреты
Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**:
- `TELEGRAM_BOT_TOKEN` — токен из шага 1
- `TELEGRAM_CHAT_ID` — id из шага 2

### 5. Запусти
**Actions → Design news → Telegram → Run workflow.**
Первый запуск пришлёт 5 свежих материалов, дальше бот будет слать только новое.

## Настройка — всё в `config.json`

| Что | Где |
|---|---|
| Добавить источник | `feeds`: имя, ссылка на RSS, `filter: true` — фильтровать по словам, `false` — брать всё |
| Что считать дизайном | `keywords` — можно писать начало слова: `айдентик` поймает «айдентику» |
| Что отсекать всегда | `stop_words` |
| Сколько постов за раз | `max_posts_per_run` |
| Сколько слать при первом запуске | `first_run_send_last` |

**Расписание** — строка `cron` в `.github/workflows/design-news.yml`
(сейчас каждый день в 9:55 МСК = 6:55 UTC; GitHub обычно запускает с задержкой на несколько минут).

## Проверка на своём компьютере

```bash
pip install -r requirements.txt
DRY_RUN=1 python bot.py   # напечатает посты в консоль, ничего не отправит
```

## Как это устроено
- `bot.py` скачивает ленты, отбирает материалы по словам и шлёт в Telegram.
- `seen.json` хранит уже отправленные ссылки. Его коммитит сам Actions, удалять не нужно.
  Если удалить — бот посчитает следующий запуск первым и пришлёт 5 последних.
- Если какая-то лента недоступна, бот пропускает её и работает с остальными.
- GitHub отключает расписание в репозиториях без активности 60 дней.
  Здесь это не грозит: каждый запуск с новостями делает коммит.
